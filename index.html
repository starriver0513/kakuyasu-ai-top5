STEP 07

格安AIに入れてはいけない情報のチェックリスト

全部を怖がる必要はありません。渡す前に確かめるだけで、格安AIも安心して使えます。

公開済みの情報、一般的な質問、アイデア出し、自分で書いた文章の手直しなどは、どんどん渡して大丈夫です。下のチェックに引っかかるものだけを外す、という使い方をしてください。

入れる前に確かめること

  • パスワード・ログイン用の認証コード・APIキーが入っていないか。中国のAIには入れない（ほかのAIにも基本は入れない）
  • 名前・住所・電話番号・メールアドレスなどの個人情報が入っていないか。中国のAIには入れない
  • お客さんの情報（名簿・問い合わせ文・購入履歴・LINEのやり取りなど）が残っていないか。中国のAIには入れない
  • 仕事の機密（公開前の売上・契約書・取引先との秘密の情報など）が入っていないか。中国のAIには入れない
  • 健康・お金の口座・身分証など、特に慎重に扱う情報が入っていないか
  • 迷ったら、名前を「Aさん」に置き換え、数字をぼかしてから渡す。判断がつかなければ、個人情報は外す
  • そのAIのデータがどこの国に保存されるかを見たか（下の表）
  • 入力が学習に使われる設定のままになっていないか。オフにできるならオフ、できないなら入れる内容を絞る
  • 👍👎の評価を押していないか。学習をオフにしていても、評価した会話は学習に使われることがある
  • 会話の共有リンクを作る時、個人情報が入っていないか
  • どのAIでも、渡す前に「お客さんの個人情報が残っていないか」「このAIサービスに渡していい情報か」を確かめる。利用規約とプライバシーポリシーを一度は見る

国の機関が出している情報

DeepSeekについては、日本の個人情報保護委員会が2025年2月3日に「DeepSeekに関する情報提供」を出しています。使うことを禁止したものではなく、次の2点を知った上で判断してほしい、という案内です。

  1. 入れたデータは、中国にあるサーバーに保存されるサーバーは、データを置いておくコンピューターのことです。
  2. そのデータには、中国の法令が適用される個人情報保護法・データセキュリティ法・国家情報法などの中国の法律が例に挙げられています。
個人情報保護委員会「DeepSeekに関する情報提供」 個人情報保護委員会「生成AIサービスの利用に関する注意喚起等」 IPA「AI利用者のためのセキュリティ豆知識」

Claude Codeにつなぐ手順（デスクトップアプリ）

格安AIのサイトでAPIキーという鍵を作り、Claude Codeの設定に、その会社の接続先と一緒に入れるだけです。

Claude Code（パソコンの上でAIに作業をさせるためのツール）は、中で動くAIを格安AIに替えられます。つないでいる間は、Claudeのプランの上限はかからずに、格安AIの料金で作業を続けられます。この章は、Claudeのデスクトップアプリ（Codeタブ）で使う前提で説明します。

先に知っておくこと

  • デスクトップアプリは、アプリの中の設定画面で接続先を変えます。「サードパーティ推論（Third-Party Inference）」という、いつもとは別のモードで動きます
  • このモードでは、Anthropicのアカウントにサインインしません。ClaudeのプランのPro・Maxは使われず、つないだ会社に、使った分だけ料金を払います
  • Claude Codeを作っているAnthropicは、Claude以外のAIにつなぐ使い方を公式にはサポートしていません。動くかどうかは、各社の対応次第です
  • このモードの間は、スマホからの操作（リモートコントロール）、クラウドでの作業、音声入力などが使えません。会話の履歴も、いつものモードとは別の場所に保存されます
  • いつでも元に戻せます。起動した時のサインイン画面で、Anthropicのサインインを選べば、いつものClaudeに戻ります

ナレーション全文を読む

Claudeのデスクトップアプリで動くAIを、格安AIのDeepSeekに替える手順です。DeepSeekは、デスクトップアプリでのつなぎ方を公式に案内しています。やることは、鍵を作る、設定画面を開く、欄を埋める、の3つです。

Codexにつなぐ手順（デスクトップアプリ）

ChatGPTのデスクトップアプリのCodexは、設定ファイル（config.toml）に格安AIの接続先と鍵を書けば、中で動くAIを替えられます。

先に知っておくこと

  • Codexは、ChatGPTのデスクトップアプリの中にあります。左上のメニューで Codex に切り替えて使います
  • 設定ファイルは、アプリの中から開けます。Settings（Macは ⌘+,、Windowsは Ctrl+,）→ Configuration → Open config.toml です。ファイルの場所は、Macが ~/.codex/config.toml、Windowsが %USERPROFILE%\.codex\config.toml です
  • 書き換えたら保存して、アプリを完全に終了します（Macは ⌘+Q、Windowsは Ctrl+Q）。開き直して、新しいチャットで確かめます。ウィンドウを閉じるだけでは、設定は読み直されません
  • model や model_provider などの行は、[ ] で始まる行より上に書きます。同じ見出し（例：[desktop]）を2つ作るとファイルが壊れます。アプリが最初から書いている部分は消さないでください
  • 書き換える前に、ファイルの中身を全部コピーして、別の場所に保存しておきます。うまくいかない時に元に戻せます
アプリの中から開けない時：Macは、Finderで「移動」→「フォルダへ移動」（Shift＋Command＋G）を開き、~/.codex/ と入れると開けます。テキストエディットで書き換える時は、「"」が別の記号に自動で変わらないように、スマート引用符をオフにしてください（変わるとファイルが壊れます）。Windowsは、エクスプローラーの「表示」→「表示」で「隠しファイル」と「ファイル名拡張子（ファイル名の最後の .toml などの部分）」にチェックを入れてから、C:\Users\（ユーザー名）\.codex を開きます。

Kimi：config.toml に書く

Kimiは、鍵を設定ファイルではなく、環境変数（パソコンに覚えさせておく設定の値）に入れる方式です。デスクトップアプリには、ターミナルで設定した値が届かないことがあるので、手順が1つ増えます。

Kimi（API）：~/.codex/config.toml に足す設定 
model = "kimi-k3"
model_provider = "kimi"
model_context_window = 1048576

[model_providers.kimi]
name = "Kimi"
base_url = "https://api.moonshot.ai/v1"
env_key = "KIMI_API_KEY"
wire_api = "responses"
Kimi：Macで鍵をアプリに渡す（ターミナルで実行） 
launchctl setenv KIMI_API_KEY "ここに自分のKimiの鍵"
Kimiの注意：Macの launchctl setenv は、Kimi Code（月額）の公式ページがデスクトップアプリ向けに案内している方法です。パソコンを再起動すると消えるので、再起動のたびに実行し直し、アプリを完全に終了して開き直します。Windowsは、「設定」→「システム」→「バージョン情報」→「システムの詳細設定」→「環境変数」で KIMI_API_KEY を追加してから、アプリを開き直します。開き直した後、新しいチャットでモデルの選択欄から kimi-k3 を選びます（「Custom」と表示されることがありますが、中身は kimi-k3 です）。月額のKimi Codeを使う場合は、接続先と鍵が別になり、鍵を設定ファイルに直接書く方法も公式に載っています。
Kimi 公式：Codexで使う Kimi Code 公式：Codex（デスクトップアプリ）で使う

元のCodexに戻す方法
